# bigru-templates

Три демо-сайта доски объявлений для bigru.ee. Резиновая вёрстка, по каждому можно кликать.

Превью: https://prideman2022.github.io/bigru-templates/

- `b-vitrina/` — Витрина (Onest, терракота)
- `g-portal/` — Портал (Manrope, синий)
- `d-skandinav/` — Скандинав (Rubik, синий + красный)

В каждом: `index.html` — главная, `category.html` — выдача с фильтрами,
`ad.html` — страница объявления, `new.html` — форма подачи.

Общая основа — `assets/site.css`, палитра и шрифт каждого варианта — `<вариант>/theme.css`.

Данные объявлений взяты с работающего сайта. Выдуманных счётчиков нет, реквизиты — плейсхолдеры.
Фотографии временные, источники и лицензии — в PHOTO-CREDITS.md.
