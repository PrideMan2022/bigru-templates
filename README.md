# bigru-templates

Демонстрационные макеты главной страницы для bigru.ee — три разных направления.

Превью: https://prideman2022.github.io/bigru-templates/

- `a-doska/` — плотный список строками, левый текстовый индекс разделов
- `b-vitrina/` — неровная фотосетка, тёмная полоса вакансий
- `c-lenta/` — вертикальная панель разделов, лента, правая колонка с модулями сайта

Данные объявлений взяты с работающего сайта. Выдуманных счётчиков нет, реквизиты — плейсхолдеры.
Фотографии временные, источники и лицензии — в PHOTO-CREDITS.md.

Это не готовый шаблон DataLife Engine, а демонстрация дизайн-направления.
