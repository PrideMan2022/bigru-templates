# bigru-templates

Демонстрационные макеты главной страницы для bigru.ee.

Превью: https://prideman2022.github.io/bigru-templates/

- `b-vitrina/` — Витрина, проработана полностью (13 блоков)
- `g-portal/` — Портал: структура предложенного подрядчиком шаблона, собранная заново
- `d-skandinav/` — Скандинав: паттерн tori.fi / finn.no / blocket.se
- `a-doska/` — Доска: плотный список строками, левый индекс разделов
- `c-lenta/` — Лента: вертикальная панель разделов, правая колонка с модулями сайта

Данные объявлений взяты с работающего сайта. Выдуманных счётчиков нет, реквизиты — плейсхолдеры.
Фотографии временные, источники и лицензии — в PHOTO-CREDITS.md.

Это не готовый шаблон DataLife Engine, а демонстрация дизайн-направления.
