# bigru-templates

Демонстрационные макеты главной страницы для bigru.ee — 5 разных направлений.

Превью: https://prideman2022.github.io/bigru-templates/

Макеты свёрстаны под ширину 1440 px, данные объявлений взяты с текущего сайта, реквизиты — плейсхолдеры. Это не готовый шаблон DataLife Engine, а демонстрация дизайн-направления.
